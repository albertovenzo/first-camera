First Camera VHDL Source code
*************************

This project includes all the custom source code used to implement
a VGA Image sensor integration on a Zybo Z7 Board.

Hardware
********

- Board: ``Digilent Zybo Z7-10 Board``
- Sensor: Arducam OV7675

Features
*****

- VGA Sensor acquisition in RAW format
- Storage in DDR memory with double buffer
- Output via the HDMI connector using DVI standard
